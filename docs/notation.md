# Notation and conventions

| Symbol | Meaning |
|---|---|
| $x_i$, $\dot x_i$ | slow variables and their rates of change |
| $A$ | free energy (of the system and of any reservoir it exchanges with) |
| $\dot A$ | rate of change of the free energy, $\sum_i (\partial A/\partial x_i)\,\dot x_i$ |
| $\Phi$ | dissipation function: half the rate at which work is turned into heat |
| $R = \Phi + \dot A$ | Rayleighian; minimised with respect to the rates at fixed state |
| $\zeta_{ij}$ | friction matrix, $\Phi = \tfrac12\sum\zeta_{ij}\dot x_i\dot x_j$; symmetric and positive definite |
| $\mu_{ij}$ | mobility matrix, the inverse of $\zeta_{ij}$ |
| $\zeta$ | friction constant of one particle ($6\pi\eta a$ for a sphere) |
| $\eta$ | viscosity |
| $\xi$ | friction per unit volume between a liquid and a porous solid, $\eta/\kappa$ |
| $\kappa$ | permeability (Chapters 4 and 6); gradient-energy coefficient (Chapter 3) |
| $c$ | number density; $f(c)$ free energy density |
| $\mu$ | chemical potential, $\delta A/\delta c$ (not to be confused with $\mu_{ij}$) |
| $\Pi$ | osmotic pressure, $c f' - f$ |
| $D$ | diffusion coefficient; $k_BT/\zeta$ in a dilute solution |
| $J$, $v$ | flux and mean velocity of particles, $J = c\,v$ |
| $\delta A/\delta c$ | functional derivative |
| $p$ | pressure; the Lagrange multiplier of incompressibility |
| $a_\alpha$ | parameters of a trial solution (Chapter 5) |
| $\gamma$, $\theta$ | surface tension; contact angle (Part II); in Chapter 7 $\theta$ is the dynamic and $\theta_e$ the equilibrium angle |
| $h_J$ | Jurin height, $2\gamma\cos\theta/\rho g a$ (Chapter 6) |
| $\phi$ | porosity (Chapter 6); concentration of a solute (Chapter 9); volume fraction of particles (Chapter 10) |
| $\Omega$ | volume of a drop (Chapter 7) |
| $S$ | spreading coefficient, $\gamma_{SV} - \gamma_{SL} - \gamma$ (Chapter 7) |
| $h_c$, $R$ | thickness at the centre and radius of the wetted circle of a drop (Chapter 7) |
| $b$ | microscopic cut-off at a contact line; thickness of a precursor film (Chapter 7) |
| $\ell$ | the logarithm $\ln(h_c/b) - 1$ in the friction of a liquid wedge (Chapter 7); elsewhere a length |
| $\xi_{\rm cl}$, $\xi_{\rm hyd}$ | friction constant of a contact line; its hydrodynamic part, $3\eta\ell/\theta$ (Chapter 7) |
| $a_0$, $\tau$ | initial radius of the drops; time scale $\eta a_0/\gamma$ (Chapter 8) |
| $x$, $L$, $P$ | half-width of the neck; half-length of the pair; perimeter (Chapter 8) |
| $m$, $\Omega(\zeta)$ | parameter and conformal map of Hopper's exact solution (Chapter 8) |
| $V$, $J$ | volume of a drop; evaporation flux, volume per unit area and time (Chapter 9) |
| $k_{\rm cl}$, $k_{\rm ev}$ | line friction relative to the friction of the wedge; relaxation time over evaporation time (Chapter 9) |
| $\mu$ | deposit, solute per unit area left on the solid (Chapter 9) |
| $v_c$, $\Delta\rho$ | volume of a particle; density of the particles minus that of the solvent (Chapter 10) |
| $\tilde\Pi$ | osmotic pressure in units of $k_BT/v_c$ (Chapter 10) |
| $\xi(\phi)$, $K(\phi)$ | friction between particles and solvent per unit volume; hindrance function, $U/U_0$ (Chapter 10) |
| $D_0$, $U_0$ | diffusion coefficient and settling velocity of a single particle (Chapter 10) |
| $D_c$, $U$ | collective diffusion coefficient; hindered settling velocity (Chapter 10) |
| $\ell_g$, $\alpha$ | gravitational length $k_BT/v_c\Delta\rho g$; height of the vessel over $\ell_g$ (Chapter 10) |
| $\mathbf u$, $\theta$ | displacement of a gel network; its divergence, $\nabla\cdot\mathbf u$ (Chapter 11) |
| $K$, $G$, $M$ | osmotic bulk modulus, shear modulus and longitudinal modulus $K + \tfrac43G$ of a gel (Chapter 11; in Chapter 10 $K$ is the hindrance function) |
| $\Pi_0$ | swelling pressure of a gel (Chapter 11) |
| $f$, $D$ | friction of the network, $\xi/(1-\phi)^2$; collective diffusion coefficient of a gel, $M/f$ (Chapter 11) |
| $\tilde\varepsilon_{ij}$, $\sigma_{ij}$ | shear part of the strain; stress of the network (Chapter 11) |
| $\alpha_n$ | roots of the boundary condition of a swelling sphere, Eq. (11.13) |
| $\phi$, $\chi$, $N$ | volume fraction of A in a blend; Flory–Huggins parameter; chain length (Chapter 12) |
| $\kappa$, $\Lambda$, $\mu$ | gradient coefficient; Onsager coefficient of interdiffusion; exchange chemical potential (Chapter 12) |
| $\phi_e$, $\gamma$ | binodal composition; interfacial tension (Chapter 12) |
| $\omega(q)$, $q_m$, $\ell$ | growth rate of a fluctuation; fastest wave number; domain size (Chapter 12) |
| $\mathbf R_n$, $N$, $b$ | bead positions, number of beads and rms bond length of a Rouse chain (Chapter 13) |
| $k$, $\zeta$ | spring constant $3k_BT/b^2$; friction of a bead (Chapter 13) |
| $\lambda_p$, $\tau_1$ | relaxation rate of Rouse mode $p$; Rouse time $1/\lambda_1$ (Chapter 13) |
| $\mathbf u$, $g(t)$, $G(t)$ | end-to-end vector; mean-square displacement of a bead; stress relaxation modulus (Chapter 13) |
| $\dot\varepsilon$, $\mathrm{Wi}$, $Q$ | strain rate; Weissenberg number $\dot\varepsilon\tau_1$; maximum length of a FENE spring (Chapter 13) |
| $\mathbf n$, $\phi$, $\theta$ | director; twist angle in a twist cell; angle of the director in the shear plane (Chapter 14) |
| $K_2$, $K$, $\gamma_1$ | twist elastic constant; single elastic constant; rotational viscosity (Chapter 14) |
| $\chi F^2$, $F_c$, $h$ | field energy coefficient ($\varepsilon_0\Delta\varepsilon E^2$ or $\mu_0\Delta\chi H^2$); Fréedericksz threshold; $F/F_c$ (Chapter 14) |
| $\tau_0$, $\tau_{\rm on}$ | switch-off time $\gamma_1d^2/\pi^2K_2$; switch-on time (Chapter 14) |
| $\gamma_2$, $\lambda$, $\theta_L$, $\mathrm{Er}$ | flow-coupling viscosity; $-\gamma_2/\gamma_1$; Leslie angle; Ericksen number $\gamma_1\dot\gamma d^2/K$ (Chapter 14) |

Conventions:

* The dissipation function carries the factor $\tfrac12$: the rate of dissipation is
  $2\Phi$, and at the minimum of the Rayleighian $\dot A = -2\Phi$.
* Numerical work is in dimensionless units, stated in each chapter.
* A result is "checked" when it has been compared with an exact solution or with a
  numerical solution accurate enough for the comparison, and the size of the
  difference is printed in the notebook.
